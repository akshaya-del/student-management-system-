Base template for an internship project. Sensor values are simulated client-side in startSimulatedFeed() — replace that function with a real MQTT/WebSocket subscription or a polling fetch() call to your hardware (soil moisture probes, DHT22/DHT11 for temperature & humidity, etc.). As long as you call render() with the same zone shape ({ id, name, crop, emoji, span, moisture, temperature, humidity }), everything else — status scoring, the chart, and the recommendation engine — keeps working unchanged.
